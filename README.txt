#Тараканьи бега

Практическая работа: создание игры «Тараканьи бега» на Windows Forms (C#) в Visual Studio.

##О проекте

Это простая игра для двух игроков. Каждый игрок вводит своё имя и выбирает таракана.
После нажатия кнопки «СТАРТ» тараканы бегут по дорожке слева направо случайными шагами.
Побеждает тот, чей таракан первым доберётся до финиша. Имя победителя выводится на экран.

##Что использовано

- Язык: C#
- Платформа: .NET 8, Windows Forms
- Среда разработки: Visual Studio 2022
- Компоненты формы: "Label", "TextBox", "Button", "Panel", "PictureBox", "Timer"

##Как играть

1. Введите имена игроков в два текстовых поля.
2. Нажмите кнопку **«СТАРТ»**. Если одно из имён не введено, появится сообщение об ошибке.
3. Следите за гонкой: под полями ввода отображается пройденный путь каждого таракана.
4. Когда один из тараканов финишировал, появится сообщение «игрок … победил!».
5. Кнопка «сброс» возвращает тараканов на старт и очищает результаты, после чего можно сыграть снова.

##Как я это сделал

1. Создал проект Windows Forms и задал размер окна.
2. Нарисовал двух тараканов и сохранил их как изображения ("tarakan1.png`, "tarakan2.png") размером 161×78.
3. Разместил на форме два "TextBox", три "Label","Panel", два "PictureBox" и две кнопки.
4. Загрузил изображения в "PictureBox". Размер элементов совпадает с размером картинок, а цвет фона "Panel" совпадает с фоном изображений (белый).
5. В "Form1_Load" обнулил метки и поставил тараканов в стартовую позицию.
6. Объявил глобальные переменные:
   "name1", "name2" — имена игроков;
   "flag1" — состояние игры (0 — тараканы стоят, не 0 — бегут);
   "x1", "x2" — горизонтальные координаты тараканов.
7. Написал обработчик кнопки «сброс»: он очищает метки, возвращает тараканов на старт и обнуляет "flag1", "x1", "x2".
8. Написал обработчик кнопки «СТАРТ»: проверяет, что оба имени введены, и устанавливает "flag1 = 1".
9. Добавил компонент "timer1" ("Enabled = True", "Interval = 50") и написал обработчик "timer1_Tick".
10. Определил координату финиша: сдвинул "pictureBox1" до правого края дорожки и посмотрел первое значение свойства `Location`. У меня это 882.

##Как работает движение

В обработчике "timer1_Tick" на каждом тике, пока игра идёт ("flag1 != 0"):

- с помощью `Random` генерируется случайный шаг от 0 до 7 для каждого таракана;
- шаг прибавляется к координатам "x1" и "x2";
- значения выводятся в "label1" и "label2";
- свойству "Left" у "pictureBox1" и `"pictureBox2" присваиваются новые координаты.

Если "x1" или "x2" достигла 882, игра останавливается ("flag1 = 0"), а в "label3" выводится имя победителя.

##Запуск

1. Склонируйте репозиторий или скачайте архив.
2. Откройте "TarakanBega.csproj" в Visual Studio 2022
   (нужна рабочая нагрузка «Разработка классических приложений .NET»).
3. Нажмите F5 для запуска.
